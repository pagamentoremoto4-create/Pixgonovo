# V74 — Intervalo dos anúncios em grupos

- Opções de repetição: 2, 4, 12 ou 24 horas.
- O anúncio ativo inicia em seguida e repete todos os dias.
- Mantido o intervalo aleatório em segundos entre cada grupo.
- O próximo envio é salvo no banco e continua após reinício do Render.
- Campanhas antigas recebem frequência padrão de 24 horas.

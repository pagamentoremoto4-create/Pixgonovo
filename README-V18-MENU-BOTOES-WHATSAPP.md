# V18 — Menu com botões no WhatsApp

No primeiro acesso, o cliente recebe uma saudação personalizada com o nome capturado automaticamente e o botão **📋 Abrir menu**.

Nos próximos acessos, ao digitar `menu`, aparece somente o nome do cliente e o botão **📋 Abrir menu**.

A lista contém: Serviços, Comprar eSIM, Histórico, Minha conta, Pagar / PIX e Suporte.

Se o WhatsApp não aceitar a lista interativa, o bot envia automaticamente o mesmo menu em texto para não interromper o atendimento.

Todas as correções da V17 foram mantidas.

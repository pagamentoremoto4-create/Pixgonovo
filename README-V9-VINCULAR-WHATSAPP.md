# V9 — Vincular Telegram e WhatsApp

## Fluxo

1. No Telegram, abra o menu e toque em **🔗 Vincular WhatsApp**.
2. O bot gera um código de 6 dígitos, válido por 10 minutos.
3. Envie o código para o WhatsApp da CentralUnlocker.
4. O sistema identifica automaticamente o número que enviou o código e vincula à conta do Telegram.

## Resultado

- Uma única conta.
- Mesmo saldo, histórico, pedidos e preços nos dois canais.
- Pedidos existentes do cadastro criado pelo WhatsApp são transferidos para a conta do Telegram.
- Atualizações de pedido são enviadas para Telegram e WhatsApp quando ambos estiverem vinculados.

## Segurança

- Código de uso único.
- Validade de 10 minutos.
- Um WhatsApp já vinculado a outra conta do Telegram não pode ser reutilizado.

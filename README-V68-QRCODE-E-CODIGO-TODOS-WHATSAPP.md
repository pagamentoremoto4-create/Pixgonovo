# V68 — QR Code e código de pareamento nas 3 sessões

Implementado no painel `/admin/whatsapp`:

- WhatsApp Suporte: QR Code ou código de pareamento.
- WhatsApp Serviços: QR Code ou código de pareamento.
- WhatsApp Anúncios: QR Code ou código de pareamento.
- Campo de número com DDI + DDD em cada sessão.
- Exibição do código no painel e status `AGUARDANDO_CODIGO`.
- Cada sessão continua usando sua própria pasta, sem misturar logins.

Para conectar por código, informe somente números, por exemplo `5511999999999`. Depois abra no celular:

WhatsApp → Aparelhos conectados → Conectar aparelho → Conectar com número de telefone.

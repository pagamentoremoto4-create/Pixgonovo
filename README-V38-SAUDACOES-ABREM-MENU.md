# V38 — Saudações abrem o menu no WhatsApp

Alteração aplicada no atendimento do WhatsApp:

- `Oi`, `Olá`, `Ola`, `Bom dia`, `Boa tarde` e `Boa noite` abrem o menu principal.
- `Menu`, `Início`, `Inicio` e `Start` também abrem o menu.
- Pontuações simples são aceitas, por exemplo: `Oi!`, `Olá.` e `Menu?`.
- A sessão anterior é limpa antes da abertura do menu, mantendo o fluxo consistente.

O restante das funções da versão 37 foi mantido.

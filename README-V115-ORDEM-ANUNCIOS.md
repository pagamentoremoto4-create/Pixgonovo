# V115 — Ordem fixa dos anúncios

A ordem de envio da Central de Anúncios foi definida como:

1. WhatsApp Status
2. Telegram
3. WhatsApp Grupos

A ordem vale tanto para campanhas automáticas/recorrentes quanto para o botão Enviar agora. Nos grupos, permanece o intervalo em minutos entre um grupo e outro; depois do último grupo, a campanha recorrente aguarda as horas configuradas antes da próxima rodada.

# V61 — Correção da IA para preços e contexto

- Inclui produtos/eSIM e serviços ativos no contexto comercial da IA.
- Serviços levam preço, prazo, descrição e disponibilidade.
- Perguntas curtas como “qual preço?” usam o assunto anterior.
- Não exibe IDs internos.
- Não nega preços cadastrados.
- Não força MENU/COMPRAR/SERVICOS antes de responder.
- Remove o rodapé automático de comandos em todas as mensagens.
- Regras novas são aplicadas mesmo quando existe instrução antiga salva no painel.

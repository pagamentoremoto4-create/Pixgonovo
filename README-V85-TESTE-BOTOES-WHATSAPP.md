# V85 — Teste de botões no WhatsApp

Na aba **Destinatários de avisos**, cada destinatário do tipo WhatsApp agora possui o botão **🔘 Testar botões**.

O teste envia uma mensagem interativa isolada com três respostas rápidas:
- 👍 Funcionou
- 👎 Não apareceu
- ❌ Cancelar

A função não altera pedidos nem status de serviços. O resultado do envio fica registrado na coluna de status do destinatário.

Observação: mensagens interativas via Baileys dependem da compatibilidade da versão atual do WhatsApp. Caso o painel informe sucesso, mas o aplicativo não mostre os botões, os avisos reais devem continuar usando texto normal.

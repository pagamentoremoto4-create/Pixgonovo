# V37 — IA removida e pagamento direto corrigido

- Removida totalmente a integração Gemini do atendimento WhatsApp.
- Mensagens fora do fluxo agora orientam o cliente a digitar `menu`.
- Corrigido o estado de saldo insuficiente na compra de eSIM.
- A opção **1 — Pagar este serviço** agora solicita CPF/CNPJ e gera o PIX.
- Após a confirmação do PIX, o eSIM é entregue automaticamente quando houver estoque.
- Sem estoque, é criado um pedido manual já marcado como cobrado.
- O saldo parcial disponível é utilizado apenas uma vez.

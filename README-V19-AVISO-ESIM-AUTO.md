# v19 - Aviso de eSIM Automático no Telegram do Admin

Correção aplicada:
- Quando um eSIM é entregue automaticamente, o administrador recebe aviso no Telegram.
- O aviso inclui cliente, plano, valor, pedido, estoque QR usado e status FINALIZADO.
- Mantida a entrega automática para o cliente.

Variável necessária no Render:
ADMIN_TELEGRAM_ID=5319809013

# V69 — Proteção ao gerar código de pareamento

- Verifica se cada sessão já possui credenciais registradas antes de gerar código.
- Não apaga automaticamente uma sessão conectada ou expirada.
- Mostra uma mensagem orientando clicar em **Desconectar** primeiro.
- Depois de desconectar, o botão **Gerar código de pareamento** funciona com uma sessão limpa.
- Aplicado a Suporte, Serviços e Anúncios.

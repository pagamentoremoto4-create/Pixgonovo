# V112 — Intervalo em minutos entre grupos

- Central de Anúncios permite digitar um intervalo fixo em minutos entre um grupo e outro.
- Campanhas recorrentes permitem digitar livremente quantas horas esperar para repetir a rodada.
- A contagem da recorrência começa somente depois que a rodada atual termina.
- Configurações são salvas individualmente em cada campanha e podem ser editadas depois.
- Mantidas as correções e funcionalidades da V111.

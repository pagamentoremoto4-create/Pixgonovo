- Menu principal agora usa botões inline do Telegram.

- Cliente ainda digita apenas IMEI, Lock Code, texto livre ou valor personalizado do PIX.
- Botões de pagamento rápido: R$20, R$50 e R$100.
- Botão Voltar retorna ao menu principal.

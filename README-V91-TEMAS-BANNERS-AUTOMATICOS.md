# V91 - Temas com banners automáticos

- Cada tema possui sua própria imagem/banner.
- A tela Temas mostra a foto real de cada tema.
- A pré-visualização mostra o banner antes de aplicar.
- Ao aplicar, o Dashboard carrega automaticamente o banner correspondente.
- O tema continua salvo em `painel_tema` no banco persistente em `/data`, portanto permanece após reinício/deploy do Render.
- A opção de imagem manual permanece apenas como personalização opcional.

# Alteração V7 — Menu do WhatsApp

## Cliente novo
No primeiro contato pelo WhatsApp:

1. O número é cadastrado automaticamente, sem informar ao cliente que o cadastro foi criado.
2. O sistema envia automaticamente:

Olá! Seja bem-vindo à CentralUnlocker.

Como posso ajudar você hoje?

1️⃣ Serviços
2️⃣ Comprar eSIM
3️⃣ Histórico
4️⃣ Minha conta
5️⃣ Pagar / Pix
6️⃣ Suporte

## Cliente já cadastrado

- Mensagens avulsas não abrem o menu automaticamente.
- Para iniciar ou reiniciar o atendimento, o cliente deve digitar `menu`.
- O sistema aceita `menu`, `Menu` ou `MENU`.
- Os atalhos `inicio`, `início` e `/start` não abrem mais o menu no WhatsApp.

## Operação em andamento

Enquanto o cliente estiver escolhendo um serviço, enviando dados, comprando eSIM ou gerando PIX, o fluxo continua normalmente.
Ao digitar `menu`, a etapa atual é limpa e o menu principal volta a aparecer.

# V101 — Central Hacker Pro

Novo tema inspirado no layout de referência enviado pelo usuário.

- Menu lateral preto/verde neon
- Cabeçalho com busca, WhatsApp, relógio e Admin
- Banner grande do hacker
- Card lateral com segundo hacker e frase
- KPIs com mini-gráficos
- Status do sistema
- Gráfico de pedidos e últimos pedidos
- Cards de saldo, revendas, serviços e atividade recente
- Responsivo para celular
- Mantém os temas anteriores e as correções de WhatsApp da V100

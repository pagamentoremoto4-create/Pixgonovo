# V51 - Administração automática no Telegram

- Ao enviar `/start`, o administrador abre diretamente o painel administrativo.
- O teclado inferior mostra `🔐 Administração` e `🛒 Menu do cliente`.
- Clientes comuns continuam abrindo somente o menu normal.
- `/admin`, `admin`, `painel` e `administração` também abrem o painel.

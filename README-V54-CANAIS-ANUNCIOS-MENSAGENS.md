# V54 — Canais de anúncios e mensagens

## Painel web
- Campanhas automáticas: escolha WhatsApp, Telegram ou ambos.
- Mensagens livres: escolha WhatsApp, Telegram ou ambos.
- O envio contabiliza cada canal separadamente.

## Painel administrativo do Telegram
- Em Marketing Automático, cada campanha possui botões para ativar/desativar WhatsApp e Telegram.
- Em Mensagens Livres, escolha WhatsApp, Telegram ou ambos antes de digitar o texto.

## Segurança
- Não permite criar mensagem livre pelo painel sem selecionar ao menos um canal.
- Não permite ativar campanha pelo Telegram sem selecionar ao menos um canal.

INSTALAR / ATUALIZAR
1. Extraia o ZIP e atualize os arquivos de código do projeto.
2. Preserve o DATA_DIR existente, seu banco, sessões WhatsApp e variáveis de ambiente.
   O pacote não inclui banco, senhas, sessões privadas ou node_modules.
3. Instale as dependências com npm ci (ou o buildCommand já configurado no Render).
4. Inicie com npm start.
5. Abra /health no seu domínio. A resposta desta versão contém version: 10.1.8.

WEBHOOK OPCIONAL DE SMS
As consultas automáticas continuam funcionando sem webhook.
Para receber avisos mais rápidos, configure HERO_SMS_WEBHOOK_SECRET com um segredo
aleatório de pelo menos 32 caracteres no servidor. Não use a chave da Hero como segredo.
Gere um segredo com node -e "console.log(require('crypto').randomBytes(32).toString('hex'))".
Cadastre na Hero, caso sua conta disponibilize a configuração de callback, a URL:
https://SEU-DOMINIO/webhooks/herosms/SEU-SEGREDO
O arquivo OpenAPI documenta o evento, mas não uma API para configurar o destino.
A configuração da conta Hero precisa ser feita no provedor; não foi feita localmente.
O endpoint só usa o aviso para consultar os SMS na API autenticada; não confia no
código recebido pelo webhook e não executa operações financeiras pelo payload.
Se não configurado, o endpoint fica indisponível. Não exponha essa URL com segredo.
